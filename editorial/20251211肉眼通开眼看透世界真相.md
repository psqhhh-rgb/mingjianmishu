## 一、什么是"肉眼通"

所谓"肉眼通"，核心就一句话：**肉眼真的看到了**。它和你平时理解的"开天眼"不是一回事。

- **肉眼通**：用眼睛看，看见的是人与物外围的一层辉光、气场，颜色有白、灰、黄之分。
- **天眼**：另有层级，要"修出分身化身"，分身即阳神，又叫天人，"天人带的眼睛才叫天眼"，古人说它"遥看千里之外"，与五眼六神通、四禅八定十二喜枝一脉相承。

在拉手能量法的基础读本《拉手能量法基础全书》里，"看气看光训练"被明确列为"肉眼通入门"的第十五章——也就是说，它是整套体系里**最靠前、最基础、人人可练**的一环，前提只有一个：**先把能量拉足**。

## 二、肉眼通怎么练：三步入门

### 第一步：先拉手，把能量基础打牢

传承者反复强调："关键还是拉手拉出来深厚的能量，**能量足了，天眼、肉眼就都开了**。"因此不要跳过拉手直接去"看光"——手上没有能量，看到的多半是眼花的残影。

### 第二步：白底黑底看手指（看空训练）

这是最经典的起手方法，落实到细节是：

1. 选**纯黑屏幕或白墙**作背景；
2. 食指竖起，离屏约 20 厘米，眼正对屏幕、离手指约 40 厘米；
3. 把**焦点聚在指尖上方约 1 厘米的虚空处**（不用直勾勾盯着指尖）；
4. 保持姿势与焦点，持续凝视背景。

开始能看到指头边缘"一层亮、一层白"，继续盯着，会出现各种颜色。初练常先见手指边一圈白色雾气；练几天后，会在雾气里、贴手一毫米处看到一种通透的、像真空一样的颜色——**那就是"光"**。越看越亮、越看越厚，肉眼通便算是开了。

有一个方便的自检办法：用手机在纯色背景前给手拍照、放大，往往更容易看出手边的辉光或气场，说明你看到的并非幻觉。

### 第三步：从手指延伸到日常万物

指头看得稳了，就把对象换掉——去看茶杯、电视、遥控器、桌椅，会发现"上面都有一层气场"；再看宅子、商场、酒店，同样有。这一步是把"看"从训练场搬到生活场。

## 三、气场颜色怎么读（对照表）

看只是手段，**解读**才是目的。传承记录里给出了一套相当直观的对应关系：

| 看到的颜色 | 含义 |
| --- | --- |
| 白亮 | 运势好，财运好，做事顺利 |
| 灰 | 压抑、别扭、不顺 |
| 杂黄 | 破财，花钱、吃药 |
| 白兼灰 | 小有不顺 |
| 白兼杂黄 | 花钱、吃药、破财 |

| 体内灰 | 不舒服 |
| 头部白 / 头部灰 | 头脑清晰、记忆好 / 思想困扰、睡眠不好 |
| 局部有灰 | 哪里灰，哪里寒凉、不舒服、疼痛 |

## 四、肉眼通之上：脑屏、平行眼与天眼

肉眼通不是孤立的功夫，它和几项"内视"训练互相呼应，构成一条从易到难的进阶线：

- **脑屏**：想"脑海里出画面"，先练大脑屏。方法只有一句心法——**观想大脑横切面是一个平静的大海面**，只看着这一个画面，很快海面上就会浮现景象。练到好处，记忆、速算、瞬时判断都在脑屏里完成。
- **平行眼**：被称为"七田真的秘诀"。练成后，看一页书可以呈立体高清的小图浮在眼前，越远画面越小——这正是**一目十行的基础**。
- **天眼**：层级更高，需修到分身化身/阳神（天人），讲究"遥看千里之外"，属五眼六神通的范畴。

三者共同的前提，仍然是那句老话：**先把能量拉出来**，能量足了，感官的"开关"才谈得上被打开。

## 五、从"看"到"用"：查病与调理

会看之后，自然的下一步就是使用。传承记录给出的进阶路径是：

1. **肉眼通**——看到人体体外的生物磁场；
2. **透视**——进一步看到体内病灶；
3. **光球放磁**——用手上光球放光、放磁，去改变病灶的颜色。

配合"祝由"的手法即可上手调理：写符字、隔空转圈、用手抓甩、顺圈逆圈——核心是**手上先有能量，手法就那么几式**。

## 六、常见问题

**问：肉眼通要练多久？**
记录里的回答是——每天坚持练，**几天就能成功**；难的从来不是难，而是很多人"说一次做一次，不说就忘了"。功夫在两个"每天去练"。

**问：会不会练出偏？**
拉手能量法的设计本身就是"不出偏"：**不采外气、修的是自身能量、不加意念、坚决不收功**。

**问：和传统"采气"有什么区别？**
本体系明确不采大地山川、日月之气，认为"采气是气功时代的错误"，能量来源于**自身内部的激发**。

**问：孩子能练吗？**
记录里有孩子坚持练功后精力变足、上课反应变快的反馈。需要注意：**不追求立刻出功能，先把精神状态练好**。

## 七、修炼提醒

- 先能量、后感官——不要跳过拉手直接"看光"；
- 练"看空"时放松，不较劲、不追求立刻看到颜色；
- 顺其自然、不加意念，是本法一以贯之的原则；
- 把它当作观察自身状态的一面镜子，而非焦虑的来源。
