## 一、什么是紫薇讳

**紫薇讳就是紫薇大帝（紫微北极大帝）的名号**，在道教符字体系里被写成一组特定的"讳字"。传说**紫薇大帝掌管二十八星宿**，因此以紫薇讳行法，是"**借用大帝的能量来治疗各种疾病**"。

据传承记录，紫薇讳的特点是"**手诀、咒语、符字结合一体**"——在紫鸢真人（温州玄武桩法传人）一脉中传承，也见于道门各流派。

## 二、紫薇水法（核心做法）

1. **备水**：一杯**阴阳水**——即提前备好的**雨水**。
   - 注意：**阴阳水是喷在病人病患处用的（祝由噀水），不能喝**；
   - 也可用自来水，配五龙水咒替代。
2. **结三山诀**：左手结**三山诀**，托住水碗。
3. **念咒七遍**：右手剑指**画紫薇讳一遍**，同时念——
   > 化形灾减，施法秘气，心清章至，引咒炼丹，升方安神，引药气入，百病消除，吾奉太上老君急急如律令。敕。
4. **第二种用法**：剑指**直接指患处**，边念边画紫薇讳——
   > 霹雳腾空过，煞动鬼神惊。道法本无多，南辰贯北河。只用一个字，降尽世间魔。开天门，闭地户，留人门，塞鬼路，穿鬼心，破鬼肚，人来有路，鬼来无门，吾奉真武祖师急急如律令。
5. **紫薇讳画法咒**——
   > 头上青云盖，左边三点金，车动龙神现，斤字斩妖精，耳听雷声响，万吓化为尘，吾奉太上老君急急如律令。驱走邪妖精。

**画讳要诀**：**一遍画，一笔一个星宿，正好二十八星宿画完。**

## 三、二十八星宿速查

| 四象（方位/季） | 七宿 |

| 东方**青龙**（春） | 角、亢、氐、房、心、尾、箕 |
| 北方**玄武**（冬） | 斗、牛、女、虚、危、室、壁 |
| 西方**白虎**（秋） | 奎、娄、胃、昴、毕、觜、参 |
| 南方**朱雀**（夏） | 井、鬼、柳、星、张、翼、轸 |

画讳时的连读顺序：**"角亢氐房心尾箕，斗牛女虚危室壁，奎娄胃昴毕觜参，井鬼柳星张翼轸"**。

> 二十八星宿是古代天文学把黄道附近恒星划分的 28 组，用于观测日月五星运行，也广泛应用于历法、占星、风水。**心宿**即包含著名的"大火星"（心宿二）。

## 四、同源手法：神仙一把抓

"**神仙一把抓**"，也就是现在说的"**抓病气**"。咒：
> 仙人神掌世间少，根苗出在蓬莱岛，元始祖师他最灵，用在手掌无价宝，治病不用丸散药，神仙一抓百病好。

**操作**：右手掌放在病患处（结节、肿瘤等），念动咒语一遍，**观想把灰黑的病气抓出来、甩出去**，并做出抓甩动作，**反复七遍**。

## 五、同源手法：九龙化骨水

**专治卡刺**：
1. 三山印拿清水一碗；
2. 用剑指在水中**逆时针画圈**，同时念咒——
   > 九龙水，九龙水，九龙似海水，是钢化成泥，是铁化成水，吾奉太上老君急急如律令。
3. 念完，剑指在水中**画井字**，再往水中**画祝由符字**（写七遍）；
4. 让卡刺的人**一口喝下**。
