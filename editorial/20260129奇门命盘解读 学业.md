## 一、一句话说清奇门占学业

奇门看读书运，核心就一句：**找出盘里"代表学业的那一宫"，看它和命主（命宫）之间是相生还是相克、有没有四害、有没有吉神。**

## 二、断学业的基本逻辑

以原记录中的一个命盘为例：

| 观察点 | 记录中的判断 |
|--------|-------------|
| **自身生学业** | 主"学着累"——是命主去养学业，付出多、费力 |
| **学业宫落空** | 力气使不上，读书容易受阻 |
| **上有小人** | 学业宫遇凶神，主被人干扰、分心 |
| **事盘学业宫生命主** | 学业反过来生自己——顺，有利于出成绩 |
| **芮、死** | 天芮（病星）加死门，主"不如意" |
| **盘中无四害** | 没有刑冲墓空迫——底盘干净，是好事 |
| **上有直符护佑** | 直符为吉神、主贵人/庇护 |

综合起来就是：**"勉强能中"**——不是大吉，但有机会，**"博士，等待验证"**。

## 三、看点小结

断学业，按这几个维度过一遍：

1. **谁生谁**：命主生学业（累）／学业生命主（顺）；
2. **落空否**：学业宫落空 → 力不从心；
3. **四害**：有刑冲墓空迫 → 打折；
4. **吉凶神星门**：直符、天辅等吉神加分；芮、死等减分；
5. **综合**：几项一叠加，给出"能/不能、几分火候"的判断。

## 四、常见问题

**问：学业宫是哪一宫？**
不同流派取法略有差别（有用景门、有用"文书"相关星门、有用年命入局），本页按原记录的说法——**以盘中标出的"学业宫"为准**。

**问：命盘说学着累，是不是就别读了？**
不是。传统上"累"只代表**费劲、需要更多付出**，不是"读不成"。而且四害多数有化解/填实之法。

**问：这套能替代学业规划吗？**
不能。本页属**传统术数文化的学习记录**。**孩子的学业该看的是兴趣、方法、身心状态和科学的学习规划。**

## 五、提醒

- 断学业先看**生克关系**，再看**四害**，最后看**吉神凶星**；
- "无四害"是好底子，遇到要珍惜；
- 本页仅供**传统文化研究参考**，**不构成任何升学、教育决策依据**。
