## 一、本页是什么

原页是**高俊波"老一辈传承·奇门遁高级函授教程"（第19–28集）** 的讲稿整理。承接基础与应用，这一部分讲的是**"经验"与"定律"**——把断事从"套路"提升到"把握规律"。

（同名"完整版"讲稿见本集群另页。）

## 二、三个核心概念

### 概念一：定律 / 经验 / 规律
- 高级班的核心是**"经验"**——把高准确率、频繁出现的规律总结成**"定律"**；
- 三式（太乙、六壬、奇门）互相关联；奇门是**立体模型**（天地人神四盘压缩到一个平面）。

### 概念二：主客法的深化
- **"动者为客，静者为主"主要用于运筹**；在**占卜**中，主客按"人事关系"判断；
- **"主客判断错了，结果马上错"**——这是高级班反复强调的关键。

### 概念三：十二将神的克应
- 十二将神（子丑寅…亥）与九星、八门、奇仪同宫，产生**"克应"**（类似格局）；
- 例：**"申"将（主奔波）+ 生门（主钱财）= 钱财在流动**；
- 将神分**活将/定将**、**明/暗**——只布九个，另三个隐藏。

## 三、高级技法清单

| 技法 | 要点 |
|------|------|
| **掌上小奇门（掐指神算）** | 不用排盘，掐指起局，快速断事、测流年 |
| **四种引干** | 引干的取用与用法 |
| **暗干 / 应期干** | 暗藏信息、定应期 |
| **确定用神宫的"定律"** | 如何准确锁定用神宫 |
| **内心事的占测** | 明宫与暗宫，看"心里想的" |
| **六亲找法** | 六亲的定位与用法；财、官、鬼 |
| **大三传** | 推过去、现在、未来 |

## 四、专题应用

- **流年流月运势**：分析个人当前运势、占测流年流月、掌上小奇门测流年；
- **婚姻**：合婚、多人合婚、感情纠纷、已婚人士测感情；
- **工作事业**：看开门定整体、看六亲官位定得失、三传看脉络、主客定时机。

## 五、这套"高级"高在哪

1. **从"会不会"到"准不准"**：基础课教你排盘，高级课教你**提高准确率**；
2. **信息更深**：引干、暗干、明暗宫——把"藏起来的信息"翻出来；
3. **工具更快**：掌上小奇门，不排盘也能断。

## 六、常见问题

**问：必须先学基础和应用吗？**
是。**高级班默认你已会排盘、会基本断事**，直接看会听不懂。

**问："克应"和"格局"是一回事吗？**
关系相近。记录者的说法是：**克应就好比格局**，是符号同宫时产生的特定含义。

**问：掌上小奇门靠谱吗？**
它是术数里"快速起断"的一种方法，属**民俗技艺**。本页是**传统术数文化的学习记录**，**不作有效性判断**。

## 七、提醒

- 高级课主线：**定律 + 主客 + 十二将神克应**；
- 建议在**扎实基础**后再学，否则容易越学越乱；
- 本页仅供**传统文化研究参考**，请理性看待。
