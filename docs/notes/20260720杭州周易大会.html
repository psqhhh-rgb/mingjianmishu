杭州周易大会：术数圈的一次行业聚会

一句话结论：本页是参加杭州周易大会的见闻记录：拼房、结交舍友饭友、十人一桌、赞助商供酒，以及"各门各派传承人"到场。编者整理其往来，说明这类会议在传统术数圈里更像一场行业交流与联络活动。

一、本页是什么

原记录是一段"去不去杭州""到没到"的现场对话，主角们正赶赴一场周易大会。文字不多，但勾勒出这类大会的参会生态。本页把这些零碎对话整理成一篇见闻说明。

二、会上在"结交"什么

从对话看，参会的一大主题是广结人脉：

  • 有人张罗拼房，"这样就可以结交新朋友"；
  • 组织者"刻意安排他们分开住，就是每年结交更多不同朋友"，让老面孔每年都能遇到新面孔；
  • 除了舍友，还有饭友、酒友——"十人一桌，自由组合"；
  • 宴会上的酒由赞助商供应，"随性喝"。

可以看出，这是一种以聚会带动联络的模式：住、吃、喝都成了认识人的场合。

三、"各门各派"与人到场

记录里点名了几类人：有龙虎山的"侯斌"，也有"各门各派传承人"，还提到要"到时候合个影"。这说明大会是多门派、跨地域的集中场合，参加者身份多样，既有爱好者，也有自称有师承的传承人。

四、这类大会是什么性质

按民俗视角看，周易大会近似一场传统文化与术数圈层的行业聚会：以交流、讲座为名，实质承担了社交、结缘、展示师承的功能，更像"圈子年会"而非学术会议。参与者交换的既有术数话题，也有人脉与资源——本集群《各个协会，互相抢人，内斗》就从侧面印证了这种圈层结构。

五、常见问题

问：周易大会主要做什么？ 从本页看，主要是参会、听讲、结交：拼房、饭局、合影，交流门派与经验，社交份量不轻。

问：参加这类大会能学到真东西吗？ 见仁见智。会议以交流联络为主，系统性学习仍靠长期读盘与练习，不宜指望几天大会就入门。

问：本站怎么看这类活动？ 按民俗与传统文化交流活动客观介绍，不评断高下、不背书任何"功效"。

六、提醒

  • 会议三件套：拼房结友、同桌吃饭、合影留念；
