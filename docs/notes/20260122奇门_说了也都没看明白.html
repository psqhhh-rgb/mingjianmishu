看懂奇门盘的第一步：刑、冲、墓、空、迫（四害速查）

一句话结论：一张奇门盘上最容易让人"看不明白"的，就是那几处被标注的毛病——刑、冲、墓、空、迫（并称"四害"）。把排盘工具自动标出的这些点逐个对号，只管去化解，盘就一眼看懂了。

一、一句话说清"看不明白"的原因

很多人排出奇门盘却"看不明白"，不是不会飞盘，而是不知道从哪儿看起。诀窍是：先抓盘上的"毛病"——刑冲墓空迫。

排盘工具会把这些问题自动标注出来，你只要按图索骥，逐个化解即可。

二、四害（刑、冲、墓、空、迫）速查

术语 一句话解释 影响
空（空亡） 天干落空、当宫无气 好事到不了头，虚而不实
冲（相冲） 两地支对冲 动荡、冲突、被冲击
刑（相刑） 地支相刑（如寅巳申三刑） 内耗、纠葛、受伤
墓（入墓） 天干入墓库 被埋、施展不开
迫（门迫） 门与宫五行相克 力量被压制、别扭

排列盘工具里，这五种都会被标出来，一宫之内可能同时中好几个。

三、一个实例：好大运也会被"四害"削弱

原记录里举了一个"好大运被层层削弱"的例子：

  • 宫里有 六合（重重喜）、天心（吉星）、开门（吉门）→ 好大运；
  • 但接着：
  • 丑空 → 减弱；
  • 寅申冲 → 减弱；
  • 寅巳申三刑 → 减弱；
  • 庚金墓在丑 → 又减弱。

结论：一个宫里的空、冲、刑、墓，会把它原本的"吉"一层层削掉。

四、为什么"看四害"最实用

  1. 它不是玄而又玄的东西——排盘软件直接标出来，不用自己推；
  2. 它指向行动——看到毛病，"只管去化解就行"（填实、避开、调理）；
  3. 它决定吉凶打折——上面那个例子就是最好的说明。

五、正确用法（三步）

  1. 排出盘：用排盘工具生成命盘，多打印几张；
  2. 先标四害：把刑、冲、墓、空、迫的位置圈出来；
  3. 再谈吉凶：好格局/坏格局都要先"打过四害的折扣"，剩下的才是可用的判断。

六、常见问题

问：四害越多越不好吗？ 一般来说是的——越多说明"可用之气"越弱。但术数讲究"有气即可用"，四害也有对应的填实、化解办法，不是一票否决。

问：和"解盘顺序"是什么关系？ 四害是解盘的第一步过滤。顺序通常是：先标四害 → 再看命宫 → 再读神/星/门 → 再排大运流年。
