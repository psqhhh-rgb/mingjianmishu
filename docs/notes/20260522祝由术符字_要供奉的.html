祝由符字的供奉规矩

一句话结论：祝由/道门的符字不是画了就算——要按所请神明供奉：写关圣帝君要供奉酒肉，写伽蓝菩萨要供水供花；"事归谁管，写谁"，供品也对应该神明。这既是敬神之礼，也被视为术法灵验的前提。

一、一句话说清

祝由术里写的符字，并不只是"写下来"那么简单——有些符字是要供奉的：

写关圣帝君，就要供奉酒肉； 写伽蓝菩萨，就供水供花。

也就是说：你请哪位神明办事，就要按那位神明的规制来供奉。

二、"事归谁管，写谁"

这与祝由"符胆可换"的原理一脉相承：

  • 求财 → 写财神、写"财源广进，日进斗金"；
  • 催婚 → 写月老、"月老和合，姻缘早成"；
  • 消灾治病 → 写太上老君、真武祖师、药王华佗等；
  • 敬奉关帝 → 写关圣帝君。

供品也要对号入座：关圣帝君配酒肉，伽蓝菩萨配水与花。写谁、请谁，就供谁。

三、为什么必须供奉

  • 敬神之礼："人归谁管，写谁"——供品是对神明的恭敬；
  • 灵验前提：在传承体系里，"请神办事"讲究心诚与礼数，供奉是其中一环；
  • 规矩传承：这属于术法使用中的固定规矩，不是随意的形式。

四、和"开光科仪"的呼应

供奉规矩，与开光科仪里的原则一致——心法与礼数并重：

  • 开光阴"阳"（物件、神像）要起势赞、针开/香开/合开；
  • 符字"请神"要按神明配供品。

两处都强调：对神明的恭敬，是这门技艺的底色。

五、常见问题

问：所有符字都要供奉吗？ 记录指"这是要供奉的"——即这类请神明的符字需要供奉；具体按所请神明办理。

问：供品能随便换吗？ 不宜。"事归谁管，写谁"，供品也对应该神明（关帝酒肉、伽蓝花水）。
